# Masari – Page d'accueil (Angular 18)

## Lancer le projet
```bash
npm install
npm start        # http://localhost:4200
```

## Structure
- `src/app/navbar`  : barre de navigation (responsive, menu burger)
- `src/app/hero`    : titre, boutons, image
- `src/app/stats`   : +50 écoles / +30 filières / 100 %
- `src/app/steps`   : section « Comment ça marche ? »
- `src/app/footer`  : pied de page
- `src/styles.scss` : couleurs et styles globaux (variables CSS)
- `src/assets/hero.jpg` : image du hero (remplaçable)
